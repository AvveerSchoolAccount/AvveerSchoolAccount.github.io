## [**Fixed Linear Regression Tutorial**](https://avveerschoolaccount.github.io/-Fixed_Linear_Regression_MrA/)

This project is a corrected and enhanced version of a linear regression tutorial originally provided by Mr. Andrade. The goal was to clarify key concepts in linear regression and fix implementation issues so that the tutorial accurately demonstrates how regression models work in practice.

Using Python and Jupyter Notebook, the tutorial walks through fitting a linear model using Least Squares Linear Regression (LSLR) and visualizing the results with scatter plots and regression lines. It explains how regression coefficients are calculated, how residuals are formed, and why minimizing residual error is central to linear regression.

The project goes beyond basic regression by analyzing residual plots and residual distributions, showing how they can be used to evaluate model assumptions such as linearity and normality of errors. A statistical approach using statsmodels is also included to interpret important metrics like R², adjusted R², p-values, and confidence intervals.

In later sections, the tutorial compares different regression techniques, including:

- Ordinary Least Squares (vertical residuals)
- Regression using horizontal residuals (when X depends on Y)
- Total Least Squares (orthogonal regression), which accounts for error in both variables

By fixing errors and improving clarity, this project demonstrates when different regression methods should be used and highlights the importance of understanding assumptions rather than blindly applying models.
