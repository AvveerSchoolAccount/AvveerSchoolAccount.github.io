## [**MPG Linear Regression Assignment**](https://avveerschoolaccount.github.io/Linear_Regression_Assignment/)

This project was a linear regression competition assigned by Mr. Andrade that focused on predicting a vehicle’s miles per gallon (MPG) using automotive performance and design features. The objective was to build interpretable regression models, evaluate their assumptions, and understand how individual predictors influence fuel efficiency.

Using Python and statsmodels, I began with simple linear regression to examine the relationship between horsepower and MPG, visualizing the regression line and evaluating model fit using R² and statistical significance. I then expanded the analysis to multiple linear regression, incorporating additional variables such as cylinders, displacement, weight, acceleration, year, and origin to improve predictive performance.

The project included extensive model diagnostics, such as residual plots, QQ plots for normality, leverage and influence plots, and correlation heatmaps. These analyses were used to assess linearity, normality of errors, multicollinearity, and the impact of influential observations. I also explored interaction terms and log transformations to better capture nonlinear relationships and improve model behavior.

This assignment emphasized not only prediction accuracy, but also model interpretation and statistical reasoning, reinforcing the importance of validating assumptions and understanding how features contribute to real-world outcomes.
