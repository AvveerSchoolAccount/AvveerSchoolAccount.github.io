This project is a task I struggled with even in grade 10, as my URL did not work. In grade 11, even after understanding how hosting Jekyll-themed websites on GitHub worked, I was not doing great. The main problem I faced was finding the right balance between good-looking websites and non-complex themes.

Firstly, I would like to talk about Chirpy, one of the most complicated Jekyll-themed websites I have worked with. It required the installation of open-sourced VS Code, Docker, and other complicated instructions. Overall, I feel that making a chirpy themed website requires a lot more effort and results in you having an above average website.

Some other themes I would like to mention are Kross and Architect (Architect was recommended to me by Ivan Johnson). Both of these themes were decently looking and not complicated. In fact, I had been using the Kross theme for my website and was going to follow through had I not discovered LeNPaul's Jekyll theme.

LeNPaul's portfolio Jekyll theme looked so well-organized, especially since it had thumbnails for all the projects, that I knew I had to switch themes. Upon going over this GitHub repository (https://github.com/LeNPaul/portfolio-jekyll-theme), I came across a very well written explination on jekyll themes and how each diretory and file is supposed to be named. This explination helped me a lot since I now knew were I could find certain files and folders and would not have scan through the whole thing on repeat.
