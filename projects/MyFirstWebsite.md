This project was something I struggled with as early as Grade 10, mainly because my URL did not work properly. Even in Grade 11, after gaining a better understanding of how hosting Jekyll-themed websites on GitHub works, I still found the process challenging. The main difficulty I faced was finding the right balance between visually appealing websites and themes that were not overly complex.

First, I would like to talk about **Chirpy**, one of the most complicated Jekyll themes I have worked with. Setting it up required installing open-source tools such as VS Code, Docker, and following several detailed and complex instructions. Overall, I feel that creating a website using the Chirpy theme requires much more effort, but it does result in an above-average and highly polished website.

Some other themes I explored include **Kross** and **Architect** (the Architect theme was recommended to me by Ivan Johnson). Both of these themes looked good and were relatively easy to work with. In fact, I was using the Kross theme for my website and planned to continue with it—until I discovered **LeNPaul’s Portfolio Jekyll Theme**.

LeNPaul’s portfolio theme immediately stood out to me because of how clean and well-organized it was, especially the use of thumbnails to display projects. While going through the GitHub repository (https://github.com/LeNPaul/portfolio-jekyll-theme), I came across a very well-written explanation of how Jekyll themes work, including how each directory and file is named. This explanation helped me a lot, as I was able to quickly find specific files and folders without repeatedly scanning through the entire project.
