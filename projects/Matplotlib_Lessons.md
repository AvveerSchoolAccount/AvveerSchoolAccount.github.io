These are a series of lessons that go over basic skills for Matplotlib, including basic, multi-array, and 3D graphs. I made this series for people who want to learn ML but don’t know how to make graphs and want to do everything online.

## [Avveer’s Matplotlib Tutorials — Lesson 1: Intro to Graphing](https://avveerschoolaccount.github.io/Matplotlib_FirstLesson/)

This lesson is the first part of a beginner-friendly Matplotlib tutorial series designed for students who want to learn machine learning or data science but are new to data visualization. Lesson 1 focuses on building a strong foundation in graphing using Matplotlib in Python, entirely through an online workflow.

In this lesson, I introduce core plotting concepts step by step, starting with simple line plots and gradually expanding to scatter plots, bar graphs, and basic multi-plot graphs. Each example builds on the previous one, teaching how to input data, customize plots, label axes, add titles, and display multiple datasets on the same graph.

The goal of Lesson 1 is to make graphing approachable and practical for beginners, showing how visualizations can be created clearly and correctly before moving on to more advanced techniques in later lessons. This lesson is intended for learners who want to visualize data effectively before applying machine learning models.

Topics Covered (Lesson 1):

- Line plots
- Scatter plots
- Bar graphs
- Multi-plot graphs
- Plot labeling and basic customization



## [Avveer’s Matplotlib Tutorials — Lesson 2: Intermediate Graphing](https://avveerschoolaccount.github.io/Matplotlib_SecondLesson/)

Lesson 2 builds on the fundamentals introduced in Lesson 1 and focuses on intermediate Matplotlib techniques that are essential for organizing and presenting more complex visualizations. This lesson is designed for learners who understand basic plotting and want to create cleaner, more structured, and more informative graphs for data analysis and machine learning projects.

In this lesson, I introduce how to add grids to improve readability, how to create and customize histograms for visualizing data distributions, and how to work with subplots to display multiple graphs within a single figure. Special attention is given to explaining the difference between figures and axes, using clear analogies to help beginners understand how Matplotlib structures plots.

The lesson also demonstrates correct and incorrect approaches to multi-row subplots, showing why layout management matters and how tools like GridSpec and tight_layout() can be used to properly align multiple graphs. By the end of Lesson 2, learners are able to confidently organize several plots in one window and choose the right visualization structure for their data.

Topics Covered (Lesson 2):

- Adding grids to plots
- Histograms and frequency visualization
- Subplots (single-row and multi-row layouts)
- Figures vs. axes explained
- GridSpec for advanced subplot layout
